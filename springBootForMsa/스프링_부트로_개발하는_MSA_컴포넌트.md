## 프레임워크와 스프링 부트 
### 스프링 프레임워크의 특징
- POJO 기반의 경량 컨테이너 제공 (POJO, 스프링빈, 스프링 컨테이너)
- 복잡한 도메인을 쉽게 개발하기 위한 철학 
    - 의존성 주입: 복잡한 클래스 관계 해소
    - 관점지향 프로그래밍: 기능적 요구사항, 비기능적 요구사항 분리
    - 서비스 추상화: 각 환경에 적절한 구현 클래스를 제공하고 개발자는 추상화한 메서드만 사용하면 된다. 
- 모듈식 프레임워크 
- 높은 확장성과 범용성, 생태계 시스템 
### 스프링 부트
스프링 프레임워크를 기반으로 만들어진 프레임워크
관례에 따라 라이브러리를 미리 설정해서 제공한다. 
- 단독 실행이 가능하다
  - 빌드 플러그인을 실행하면, 단독 실행가능한 jar 파일을 생성한다. 
  - 클라우드 환경에 적합하다. (scale-out)
- 액츄에이터
- auto configuration

## 스프링 어플리케이션 기본
### 스프링 빈
- 스프링 빈 컨테이너가 관리하는 순수 자바 객체이다 
- 스프링 빈의 종류
  - 스프링 프레임워크의 기본 기능 (appliction context)
  - 설정 파일 
  - 패키지 경로에 설정된 스프링 빈 (@annotation 기반으로 정의된 빈 = 비즈니스 로직)
- 스프링 빈 컨테이너의 동작 순서
  1. 설정 파일 로딩 
  2. 스프링 빈 정의 로딩 (지정된 클래스 Path 내부의 스프링 빈 스캔 )
  3. 스프링 빈을 생성하고 컨테이너에 등록 + 의존성 주입 
  4. 구현 클래스에 따라 추가 작업 (ex PostContruct)
  5. 어플리케이션 실행 준비 완료
